# Preferências do projeto

- Responda em português brasileiro e acompanhe respostas finais e explicações substantivas com um resumo falado pelo MCP `voz_tts`, ferramenta `falar_texto`, personalidade `tecnico`. Consulte `listar_personalidades` uma vez no início da conversa. Preserve a voz padrão e as vozes removidas do servidor. Se o áudio falhar, informe a falha e continue por texto.
- Se o player do MCP falhar, o cliente local já validado é `/home/labubu/mcp-tts/venv/bin/python /home/labubu/.codex/scripts/voice_mcp.py speak --text 'resumo'`; ele aguarda a reprodução e usa a mesma personalidade. Não afirme que houve áudio sem confirmação de sucesso.
- Nunca faça downloads, extrações, instalações de dependências, builds, caches, logs ou arquivos temporários fora desta raiz. Use as pastas locais ignoradas pelo Git. Não use `/tmp` nem um projeto Unity externo para trabalhar neste jogo.
- Use `Tools/unity.sh` para executar a Unity: o launcher restringe a gravação ao projeto e mantém os caches locais. A instalação existente do Editor é somente lida.
- A cada atualização visível na Unity (cena, prefab, material, UI ou configuração visual), feche a instância anterior graciosamente, espere a janela fechar e o `Temp/UnityLockfile` ser liberado, e só então abra uma única instância nova na cena atualizada. Use `Tools/unity.sh --reopen-game`, `--reopen-preview` ou `--reopen-play` conforme a inspeção; nunca abra outra instância enquanto o projeto estiver bloqueado. Mudanças apenas de código/documentação sem efeito visual não exigem reiniciar o Editor.
- Consulte `CONTEXTO.md` antes de continuar. O Bloco 4 está com outra pessoa; preserve seus contratos e não duplique essa implementação.
- Mantenha o progresso disponível em uma cena Unity; abra o Editor quando houver uma versão para inspecionar.
